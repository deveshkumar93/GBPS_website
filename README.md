# Gyan Bharti Public School Website

A responsive school website developed for **Gyan Bharti Public School, Purnea, Bihar**.

The website provides information about the school, its leadership, facilities, activities, contact details, and other important information in a modern and responsive design.

## 🌐 Project Overview

This project is a front-end website developed using:

- HTML5
- CSS3
- JavaScript

The website is designed to work on:

- 💻 Desktop computers
- 💻 Laptops
- 📱 Mobile phones
- 📱 Tablets

## ✨ Features

### 🏫 School Homepage
- School logo and branding
- Navigation menu
- Responsive layout
- Modern school-oriented design

### 🖼️ Image Slideshow
- Automatic image slideshow
- Previous and next navigation buttons
- Slide counter
- Mouse hover pause
- Keyboard navigation
- Mobile swipe support

### 👨‍🏫 Leadership Section
Includes messages from:

- Director
- Principal
- Director-Incharge

### 📚 School Information
The website can contain information regarding:

- About the school
- School facilities
- Academic activities
- Student activities
- School achievements

### 📱 Responsive Design
The website automatically adjusts its layout according to the device screen size.

### 📞 Contact Information
Includes:

- School contact numbers
- WhatsApp contact
- Email address
- School branches
- Other contact information

### 🔗 Navigation
The website includes navigation links for accessing different sections and pages.
